# Pi setup notes

- **No RTC battery.** The Pi 5 knows the time only after NTP syncs: always boot with the network up (hotspot on before the Pi at the venue). Check `timedatectl` says "System clock synchronized: yes" before the demo. The backend holds wall-clock jobs until then and shows "clock not set" (chris.md step 10).
- **Python 3.14 through uv.** Raspberry Pi OS Trixie ships 3.13; the project runs 3.14: `curl -LsSf https://astral.sh/uv/install.sh | sh`, `uv python install 3.14`, `uv venv --python 3.14 .venv`, `sudo apt install liblgpio-dev swig build-essential ffmpeg`, `uv pip install -r backend/requirements.txt -r hardware/requirements.txt`. Escape hatch if lgpio will not build in fifteen minutes: the system 3.13 with `python3 -m venv --system-site-packages` and apt's python3-gpiozero, python3-lgpio, python3-spidev; nothing else changes.
- **ffmpeg** is a dependency: ElevenLabs clips arrive as mp3 and are converted to wav for aplay.
- **Touch rotation.** Rotate to landscape in the Screen Configuration tool (rotates image and touch matrix together); if touch still lands rotated, a libinput calibration matrix udev rule, never a rotation inside Chromium. Check: a tap lands where the finger is in all four corners.
- **Phase 9 checks:** (1) the alarm tone plays from the running service, not just a terminal; (2) `pinctrl get 17` holds `hi` with a motionless person present and drops to `lo` after the room empties; (3) a spoken echo plays through the soundbar after the tone, never instead of it.
- **The kiosk rule.** Kiosk autostart stays DISABLED until the whole project is complete and the final audit has passed; `systemctl --user is-enabled kiosk` prints disabled until judging eve. During development open the display page in a normal Chromium window, or run `deploy/kiosk.sh --now` for a look (Alt+F4 closes it). Three escape hatches once it is on: (1) `sudo touch /boot/firmware/NO_KIOSK` from a tty (Ctrl+Alt+F2), over SSH, or from any computer with the SD card in a reader, then reboot (`rm` it to restore); (2) the 20 s delay is enough to Ctrl+Alt+F2 and `systemctl --user stop kiosk`; (3) SSH from the laptop works underneath the kiosk at all times, and `systemctl --user disable kiosk` turns autostart back off.
- **Service user.** The backend runs as the kiosk user (systemd --user, `loginctl enable-linger`), never root, in groups spi, gpio, audio, video; screen blanking off; the backlight udev rule (install.sh).
